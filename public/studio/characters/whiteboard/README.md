# Whiteboard presenter sprites

Generated using the built-in image generation tool, then copied into the project. The atlas is 1536 × 1024 with true alpha transparency: back view left, smiling front view right. Head and torso are raster artwork; separate animated arm/marker layers preserve writing synchronization. No 3D presenter mesh or facial fade is used. A narrow edge-on sprite transition changes between complete views.

Asset: `presenter-sprites-v1.png`.

## Generation prompt

Use case: illustration-story. Asset type: production 2D paper-doll sprite atlas for a whiteboard explainer web app. Generate ONE transparent PNG sprite sheet, landscape 1536x1024, with exactly TWO equal 768x1024 cells side by side, NO text labels. LEFT cell: BACK view of a friendly young adult male presenter. RIGHT cell: FRONT view of the exact same presenter, smiling toward viewer, brown eyes. Clean flat 2D vector-like raster illustration, smooth shapes, warm light peach skin (#f0c3a2), short chocolate-brown hair, plain violet-purple short-sleeve T-shirt (#7160ee), no logos. Both are head-and-torso paper-doll base layers, ending at a flat waist; NO legs, NO arms or hands, because arms will be animated as separate layers in the application. Only short shirt sleeve caps at the shoulder sockets; sleeves end cleanly with no arm emerging. Back view has full back-of-head hair with nape visible, no face. Front has friendly natural eyes, eyebrows, nose and smile. NO 3D rendering, NO shadows outside the sprite, NO whiteboard, NO marker, NO background, NO checkerboard painted in image. Actual alpha transparency. Both views same size and identical alignment: each head centered horizontally in its own cell; sprite top at y=80, head bottom around y=460, shoulder line around y=490, torso ending at y=940. Total silhouette width around 400 pixels within each cell, head width 300 pixels, torso width 340 pixels. Leave generous transparent padding separating the two silhouettes. Polished professional educational explainer character. Orthographic front and rear, symmetrical neutral stance. One consistent character only, two views.

## Final cleanup prompt

Edit this sprite atlas for production: preserve the exact two character designs, positions, scale, front/back views and colours. REMOVE ALL coloured glow, halo, aura, cast shadow and haze around the silhouettes. Character pixels must be fully opaque, with only 1–2 pixels of edge antialiasing. All pixels outside the actual hair, ears, neck, shirt and sleeve silhouettes must be fully transparent alpha zero. No black background, no checkerboard, no glow, no lighting effects outside the silhouette. Keep 1536x1024 two equal cells, back view left, front view right, armless torso layers. Do not add arms, hands, legs or text. This is a clean hard-edged transparent PNG cutout sprite asset, not a glowing illustration.
